# Bloom & Bliss — Flowers by Anusree

A responsive flower shop website concept built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to provide the live URL.

## Customize before launch
- Replace the sample product prices and descriptions with actual shop details.
- Replace the demo email `hello@bloomandbliss.example` in `index.html` and `script.js` with the shop's real email.
- Add real phone number, delivery areas, policies and social links.
- Product photography currently loads from Unsplash and therefore needs an internet connection.
- The enquiry form uses the visitor's email app; it is not connected to a database or order-processing service.
